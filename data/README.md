# Datos

El flujo usa `pib_per_capita_countries_dataset.csv`, con una observación por país y año y las columnas `country_code`, `country_name`, `sub_region`, `year`, `gdp_per_capita` y `gdp_variation`.

El dataset incluido se usa de forma local. `DATA_PATH` en `.env` puede apuntar a otro archivo con esas columnas. El repositorio ignora la base de datos de MLflow y los entornos locales; no agregues credenciales ni datos privados al repositorio.
